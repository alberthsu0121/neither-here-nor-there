# **羽球 向後飛 向前打 胸椎 前壓 肩膀 手肘 旋轉 動力鏈**

- 羽球 87% 都是 **向後飛** **向前打** 曁 **球高往後退**
  - 對稱的一句是：**球低往前走**  -> **接吊球**
- **棒球投球** **網球發球** **排球扣球** 比較沒有 **向後飛** 情境
- 趁著 **向後飛** 做 [**側身/半側身 弓身**](turning-sideways-arching.md)
